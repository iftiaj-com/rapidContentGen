# Regression

Each feature in this project was proven with a short test video before it was ticked in
`docs/PORTING_CHECKLIST.md`. The notes for those tests (`R0`, `R1` ... one folder each, with a
`README.md` of how it was made and an `expected.json` of what passing means) live here.

This folder is git-ignored apart from this file. The tests were built from media on one machine
(local folders, personal test clips, files inside old jobs), so they cannot run anywhere else, and
they do not come with the repo. If you add features, keep your own notes here the same way.

Nothing in the app reads this folder. Making videos does not need it.
