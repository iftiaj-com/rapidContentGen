# Capabilities

What this workspace can do today, how to call it, and what is still coming. The agent reads this
before planning a job. Status: **ready** (built and verified in a regression job), **built** (built,
not yet regression-verified), **planned** (phase in `PORTING_CHECKLIST.md`).

## Workspace tools (`node tools/rcg.mjs <command>`)

| Command | What it does | Status |
|---|---|---|
| `doctor` | Checks config, ffmpeg (including the edge test for the ffmpeg HyperFrames uses), the HyperFrames CLI (plugin launcher or npx), Python 3.11, voice venv, Kokoro weights, the MediaPipe files, the browser `rcg fx` will use (WebGPU needs an installed Chrome), sources, provenance | ready |
| `skills sync\|check` | Copies the project skills from `.agents/skills/` (edit here; Antigravity reads it) to `.claude/skills/` (Claude Code reads only that). Skips HyperFrames' own git-ignored skills. `check` lists differences; `doctor` shows it | ready |
| `new-job` | Creates `jobs/<date>-<slug>/` from a template, or from an earlier job's edit with `--like jobs/<id>` (no footage or renders; `JOB.md` lists the assets to supply); copies media; probe + safe-zone sheet; `JOB.md` | ready |
| `beat-sheet validate\|md` | Validates `beat-sheet.json` (overlaps, no-text zones) and writes the approval table | ready |
| `probe` | Streams, fps, duration, loudness, true peak, plus intake notes (no audio, low fps, hot peaks) | ready |
| `sheet` | Labeled contact sheet; `--safe` draws the 9:16 no-text zones | ready |
| `limit` | Peak-limits audio at 4x oversampling to a true-peak ceiling (default -2.5 dBTP) | ready |
| `mix-check` | Rebuilds a composition's mix offline; predicts HyperFrames' whole-mix gain cut within about 0.3 dB | ready |
| `measure-sfx` | Measures onset, crest window, audible end, LUFS and true peak for `library/sfx` | ready |
| `render` | mix-check, HyperFrames render (log saved), then `verify` with a frame sheet | ready |
| Camera measurement | `python -I tools/media/camera_motion.py <video> [--json f]` (image Python): zoom events (ratio, duration), cuts and drift per segment via ORB matching; learns camera rules from a reference and checks a render | ready (R11) |
| `verify` | Dimensions, fps, duration, no dead (black) strip at a frame edge, audio present and not silent, LUFS, true peak, silence windows, "Audio lowered" in the log | ready |
| `voice voices\|effects\|say\|transcribe\|selftest` | Local Kokoro voiceover (54 voices, 9 languages), 33 voice effects + EQ/ambiance/normalize chain, faster-whisper word times aligned to the script, `audio_meta.json` + SRT. Python 3.11 venv; nothing downloads | ready (R1) |
| `level` | Sets integrated loudness as heard (mono is made dual-mono first), then limits peaks; `--dir` for a folder of lines | ready (R1) |
| `captions` | Word timings (audio_meta.json, words JSON or SRT) -> caption sub-composition in an Adits style (tiktok, karaoke, neon, kinetic, modern, subtitle, glitch, retro, earthquake, vertical_ghost) or a style-pack style (collage, editorial, editorial-clean, vox, mp-body, mp-body-dark: font files, edge, shadow, tilt, rise or blur entrance, two-tier `layout: tier`); `--emphasis` sets chosen words in the pack's emphasis face; word / 2word / phrase modes; fits the safe box. | `style` | Style packs (`docs/styles.md`): `apply` copies a pack's fonts, writes its `frame.md` design spec, tokens and `@font-face` into the job; `add` / `build` turn components into sub-compositions from params or a plan file (`data/style-plan.json`): text fitted with canvas metrics after the fonts load, seeded tilts, boxes refused outside the safe area (tilt included), hosts kept under captions, `--sfx` places each component's sound with its peak on the landing on a free lane. Packs: `tactile-collage` (paper-ground, paper-card, headline, stamp, checklist, route, file-tag, scribble, taped-photo), `quiet-editorial` (canvas, headline, doc-card, list with cursor, progress, status, window) `vox-parallax` (parallax multiplane camera, highlight, serif-title, board, photo-card, archive) and `info-graphics` (ground, stack, equation, stairs, pyramid, photo, collage, post, prompt, orbit, counter, icon; caption preset `info-chip`). Skills: `style-tactile-collage`, `style-quiet-editorial`, `style-vox-parallax`, `skill-info-graphics` | ready (R9a, R9b, R10) |
| `layers` | A photo or clip frame cut into depth layers for 2.5D parallax: MediaPipe EfficientDet finds objects (`--detect`), magic_touch cuts one per label, click point or box, the selfie mask helps on people; OpenCV (`bin.imagePython`) keeps the clicked piece, gives each pixel to its front-most layer, feathers, stretches occluded edges straight behind front layers (`--extend`) and fills the background (Telea, softened). Writes `assets/layers/<name>/`, `data/layers-<name>.json` and a check sheet. About 4 s vision + 3-5 s OpenCV at 1080x1920 | ready (R10) |
| `marketing-pro` | Promo talking-head edits from one ordinary clip: `prep` (CFR 30, lanczos upscale + light denoise/sharpen when small, high-pass + `afftdn` + level the voice, transcript of the leveled voice, optional `--trim`, index scaffold), `plan` (beats from punctuation, conjunctions and long-clause splits, onsets snapped to the speech envelope; face-cue camera: eased 0.27 s zooms 1.3/1.0 at beat starts 1.4-3.2 s apart, 1.6 punches on strong beats, linear drift; simulates face-reframe.js for reach (auto zoom raise) and reports the effective upscale; one hero per beat with look by meaning, placed above the eyes, tone from the sampled background, behind the head via matte + PNP; caption tone; bloom), `commands`/`build` (camera, matte, pnp, style build, captions, layers, bloom, mix-check, hf check). Caption text controls (opt-in): `--caption-fx shadow,rgb,hollow` on the body caption, `--negative-heroes N` turns up to N behind-the-head heroes on a background far from mid-grey into inverted keyword captions. Skill `style-marketing-pro` Reference looks (Video-54041, opt-in): `prep --intro/--outro` room; `plan --fill-heroes --fills` (hero look `fill`: gradient, red, gold or an image), `--clusters` (lead and tail tiers on spoken times, split around the head), `--cards` (3D photo card), `--whips N` (mirror whips at sentence starts), `--strips` + `--leak`, `--music` (looped, ducked) and whooshes; `marketing-pro audio`. | ready (R11; caption controls R11b); reference looks R15 |
| `split-screen` | Split-screen explainers from a presenter + an info video (skill `skill-split-screen-edit`, reference Video-94146): `prep` (presenter via marketing-pro prep; info clips CFR 30 with short GOPs; `rcg broll`), `plan` (layout per beat: split / a-full / b-full by openers, questions, pauses, numbers and a rhythm rule; montage of B-roll shots rotated across sources on clause onsets; static face-safe presenter crop per split window found by grid search over the MediaPipe track, side-fill fallback; background darkening through a cut-out when bright; marketing-pro face camera and two-tier titles in a-full; captions per window; light leaks and sounds), `layout` (writes index.html: panels, seam fade and shade, full-frame windows, Ken Burns, handle, highlights), `build`, `clamp` (caption hosts end with their windows), `check` (split-check: windows, B coverage, face inside the panel per frame, titles off the face, build completeness). Geometry `library/split-screen/layout.json` | ready (R12) |
| `assets` | The approved free sources (user decision 2026-10-08): `icon find|add` copies single Phosphor 2.1.1 SVGs (MIT) into `library/icons/phosphor/` with LICENSE and a sha256 manifest; `search pixabay|polyhaven|met` (Pixabay needs `keys.pixabay` in the local config and is cached 24 h; the Met uses `/v1.1/search` and keeps public-domain objects only); `fetch unsplash|pixabay|polyhaven|met` saves one file into a job's `assets/` and records source, author, page, licence and sha256 in `data/credits.json` (`--dry-run` shows URL, size and credit without saving); `credit` records a file downloaded by hand (Pexels); `credits` prints the Markdown table | built (icons, searches and dry runs tested; real fetches other than icons not yet run) |
| `infographics` | Info-graphics essays (skill `skill-info-graphics`, pack `info-graphics`): `scaffold` empties a fresh job's template for a graphics-only edit; `place-voice` lays the voice lines from `audio_meta.json` end to end (lead, gaps, per-line gaps), writes their audio elements, a music bed ducked under every line and the root duration; `resolve` turns a plan with word anchors (`@vo1:word`, `#2`, `$`, `@vo1.3`, offsets, `"end": "scene"`) into the numeric plan `rcg style build` reads and prints each item's start word | built (R13 gallery snapshots, first job rendered) |
| `broll` | Info-video analysis: scene cuts, per shot luma / motion / edge density / focus point, class `card` / `ui` / `footage` / `dark`, labelled sheet -> `data/broll.json` | ready (R12) |
| `title` | Kinetic title card sub-composition: slam, stagger-up, kinetic-pop, type-on; trailer serif or any caption style; `--color` for dark text on light footage, `--y` for any height | ready (R1b) |
| `analyze` | Music -> per-frame audio table (bass/mid/treble/vol/level, kick/snare/hat, 24 bands), kick times, and a seekable shader clock (default / pulse / flywheel / tilt). Pure function: same table every run | ready (R2) |
| `shader` | Any of the 166 AditsShaders objects as an audio-reactive layer (fill or square), driven by the audio table; BIND inputs follow their bands | ready (R2) |
| `beatflash` | Adits beat-flash words: one word per band (or kick/snare/hat) flashes and pulses on hits; effects none/neon/shadow/rgb/vertical_ghost/shake | ready (R2) |
| Beat grid | `rcg beatgrid <music> -o data/audiomap.json` (tempo, beats, downbeats, phases): HyperFrames' `analyze-beatgrid.py`, copied to `tools/audio/hyperframes/` (Apache-2.0) and run in the voice venv, so no plugin is needed. HyperFrames `beats` only reads a project's own music clip | ready (R2) |
| `camera` | Camera on footage: an element (usually a `.shot` wrapper) follows cues from the 46 Adits camera moves (whip pans, crash zooms, handheld, orbit, drone...) and the 20 Adits Virtual Camera presets (`vc.ken_burns`, `vc.lean_sweep`, `vc.dutch_angle_drift`...). Layers combine (`a/` handheld + `b/` whips); `bars=N` with `--bpm` syncs to the beat; `--kick` adds beat shake; presets take `d=`, `curve=`, `zigzag=`, `hh=` (handheld) and `react=` (bass_zoom, bass_shake, mid_sway, treble_tilt, jitter_stutter, audio_speed, needs `--audio`). `--fill blur` (default on footage: blurred copy behind revealed edges, the Adits look), `cover` (one fixed zoom per cue) or `none`. Subject-anchored cues with `--track` (rcg track): `face.zoom`, `face.punch`, `face.follow`, `face.off` (`z=` zoom, `x=/y=` where the subject sits, `k=` follow, `d=`, `ease=`), `--anchor face|eyes|hand`; a clip of another aspect is laid out uncropped so the camera can reframe it (16:9 to 9:16). `--list` prints every name | ready (R3, R3b; face cues R7) |
| `three` | Procedural three.js scene sub-composition (orb, knot, crystal, rings + seeded starfield) with the 3D camera driven by the same 46 moves; optional audio-reactive bass swell and kick shake. Moves only (presets are 2D) | ready (R3) |
| `flythrough` | flowEditor camera flythrough as a sub-composition. A JSON spec (`data/flythrough.json`) lists cards (image or video, ratio, arrival, dwell, zoom, `pathStyle` smooth/linear/arc/whip/punch/kenburns, `entrance` fade/slide-*/scale/pop, optional transition `sound`) and settings (`motion` board/cards, `arrangement` none/stack, `template` left/right/up/down/star/left-right/..., spacing, card scale, radius, background colour/texture/image). `snap` lands arrivals on the beat grid; `music` adds the song with fades, clip windows and auto-duck as a volume lane. Media is cover-cropped. `--list` prints the names | ready (R4, R4b) |
| `recipe list|show|plan|commands|build` | Edit recipes (`docs/recipes.md`): `plan` drafts a beat sheet from a style (sections snapped to downbeats, shots to beats, seeded source picks, camera cues, sounds, voice slots, flythrough specs with stills) and leaves placeholders for words and titles; `build` runs voice, assemble and every block, then mix-check and check | ready (R5) |
| `assemble` | Builds index.html from the beat sheet: shots in camera wrappers (full frame or a card over a background), black cards, music with fades and a duck under the voice, voice lines, SFX by crest, white flashes, layer order; then camera cues and ramps | ready (R5) |
| `ramp` | Speed ramp on a footage clip as a rate lane: Adits audio speed sync (`--min/--max`) or explicit points; refuses below 1x; checks the source does not run out | ready (R5) |
| `fx` | Adits footage effects and 3D environments rendered offline over a range of a clip into a new clip, placed like any footage. The unmodified Adits code runs in headless Chrome (the installed Chrome, for WebGPU) with a frame-time clock, seeded random and the Adits render loop, so the same inputs give the same clip. Effects: `ghost`, `motion-trails`, `origami`, `heat-haze` and `blow-pixels` (WebGPU), `frame-tunnel` (30 presets), `reveal-under` (5 presets), `split-screen` (linear or 10 mask shapes), `color-mask` (Adits chroma key: modes media / effect / color); the last three take side B from `--src2`. `--matte <cut-out> --apply both` also writes `<clip>-fg.webm`, the effect on the subject only (for `rcg target`). Environments: `smoke` (presets `ambient`, `jet`, `mist`), `rain`, `holo-sheen`. Anamorphic models (the footage as an Adits 3D model over a background, `rcgBackground` auto / footage / src2 / black / none, `--src2` = another background): `voxel-art`, `voxel-drop` (Rapier physics; presets `drop`, `orbit`, `tunnel`, `bursts`; `rcgDropAt` / `rcgBackAt` press Drop and Back to Plane, seconds, negative = in the pre-roll), `voxel-hole`, `voxel-magnet`, `voxel-flip`, `voxel-grow`, `particles` (9 audio dance modes; `rcgLiveColor=true` re-colours from the live frame, Adits keeps the first frame), `magic-carpet` (presets `fly`, `hang`, `flag`); and `cutout` (Canvas2D collage over any clip, 8 layouts as presets, `rcgCutoutAt "t:1;t:0"`). Magnet, Grow, Flip and Particles follow a point: `--track data/track-x.json --anchor hand|face|eyes [--hand Left|Right]` (the subject in the footage, with hand openness for the Custom Gesture modes) or `--point "t:x,y[,open];..."` (output-frame 0..1). These effects run Adits' host logic at 60 Hz, so motion does not depend on the output fps, and read Adits' own analyser (emulated) with `--audio`. Adits defaults: the model is tilted -30 (`anamPerspAngle`) and fills about 63% of a 9:16 frame's height (`anamScale=158` fills it); voxel, hole, magnet, flip, grow and carpet read darker than the footage, as in Adits (lessons 13as). `--param id=value` sets any Adits UI control, `--preset`, `--audio` (+ `--audio-offset`) drives audio-reactive controls, `--alpha` writes ProRes 4444 with alpha, `--sheet` writes a frame sheet. Adits Global Visuals and Video Jockey (one host, Adits order RGB -> Neon -> BnW / Negative -> VJ deck -> Fisheye -> Opacity): `global-visuals` (`fxRgbColors` beat colour cycle, `fxNeonMode`, `fxBnwMode`, `fxNegativeMode`, `fxFisheyeEnabled` + `fxFisheyeIntensity` 0-1, `globalOpacityEnabled` + `globalOpacitySlider`; RGB and Neon need `--audio`), and the VJ FX with every Adits preset: `vj-scan` (Depth Scan: `pulse_scan`, `neon_sweep`, `ghost_edges`, `wireframe_pass`, `deep_sonar`, `subject_reveal`, `motes`), `vj-lights` (`lit_void`, `lit_wreck`, `lit_haze`, `lit_rain`, `lit_cathedral`, `lit_dust`, `lit_rim`, `lit_ignite`, `lit_laser`, `lit_blueprint`), `vj-lightshow` (`ls_ignition`, `ls_contour`, `ls_bloom`, `ls_red_room`, `ls_flash`), `vj-beatwash` (`red_alert`, `ice_strobe`, `ember_swell`, `cold_pool`); the Global Visuals params work on them too. `--param vj.<param>=v` / `vj.<channel>.<field>=v` override a preset (`vj.tint=#00e5ff`, `vj.progress.gain=0.9`); audio presets read Adits' own `AudioEngine` (kick, beat, bands) with `--audio --audio-offset <shot start>`; `subject_reveal` needs `--subject <rcg matte cut-out>` and follows `--track` / `--point` height; Beat Wash "Light From: Pointer" follows `--point`. Audio-position presets (`neon_sweep`, `lit_haze`) pin at the far plane on loud, limited music (bass x 1.6 > 1); `lit_laser` keys on red light only. About 17-45 s per 1.5 s at 1080x1920. `--list` prints the names | ready (R6; anamorphic models R8; Global Visuals and VJ R16) |
| `track` | MediaPipe face and hand tracking (Adits' FaceLandmarker / HandLandmarker, local models) on every frame, on frame time: per-frame face box, eye centre, roll and size; hands (palm, size, pinch, open, Adits gesture labels); gesture events held 120 ms. Crop fallback for small faces. One-Euro smoothing. `--debug` draws boxes, points and hand skeletons to a clip and sheet | ready (R7) |
| `matte` | Background removal with MediaPipe's selfie segmenter (Adits' pre-baked removal): every source frame at the source rate, `assets/matte/<name>-fg.webm` (VP9 alpha) and `--plate` (hole-cut background). `--lo/--hi` threshold, `--temporal`, `--feather`, `--choke` (erode the edge rim). Best on mid shots; full-body action leaks | ready (R7) |
| `pnp` | A PNP layer (Adits PNP Mode): the footage again on top with its background removed. Aligned (text can sit between) or an offset copy (`--x/--y/--scale/--rotate/--flip`, `--media-offset` for another moment, `--filter`, `--opacity`), show windows with fade, scale or block-build entrances; follows the shot's camera | ready (R7) |
| `layer` | Puts a block (captions, title) behind or in front of a PNP (text behind the subject), with timed switches or Adits' depth rule per caption group (`--depth 0.5`: behind for the first half of each group, then in front) | ready (R7) |
| `transition` | `mirror_whip` (a slide with a mirrored edge, -webkit-box-reflect, and an SVG motion blur, centred on the cut, `--dir up|down|left|right`) and `zoom_blur` (from reference Video-54041); Adits cut transitions at a cut (plus `flash_bloom` and `light_leak`, a warm screen-blended wash for split-screen section openers): `flash_white`, `flash_black`, `glitch_punch`, `zoom_punch`, `crossfade`, plus `flash_bloom` (soft white bloom, the shot brightens and blurs on its inner wrapper); Adits curves, seeded, frame-exact; the punch moves the shot and its PNP layers together; `--remove <id>` drops a block and unwraps any inner wrapper no other block uses | ready (R7) |
| `cinema` | Adits Cinema Frames: letterbox bars (`--ud`, default) and pillarbox bars (`--lr`), each with colour, position (% of the frame, default 20) and curve (-100..100), the same paths as Adits; shown in `--show "a-b,c-d"` windows, over everything (z 90) or Midground with `--behind p1` (under the subject cut-out); `--remove <id>` | ready (R16) |
| `strips` | Cast opener / closer: vertical strips, one clip each (`file@mediaStart:subjectX`), cut in 0.53 s apart over black (`--mode open`) or flashed with an optional light-leak clip and dropped out to black (`--mode close`); untimed wrappers, timed media (from reference Video-54041) | ready (R15) |
| `target` | Effect target (Adits Effects Target), switchable by time window: `bg` = the effect clip under the clean cut-out, `fg` = the effect on the subject only (`rcg fx --matte <cut-out> --apply both` makes both clips) | ready (R7) |
| Shader catalog | `node tools/shaders/catalog.mjs --find "<look>"` searches `library/shaders-catalog.json` | ready |
